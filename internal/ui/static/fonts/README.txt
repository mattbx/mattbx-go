Both are licensed under the SIL Open Font License 1.1. The full text sits next
to the font files in the OFL-*.txt files. The woff2 files are the Latin subsets
from the Fontsource npm packages (@fontsource/victor-mono and
@fontsource/jetbrains-mono), fetched by scripts/fetch-fonts.sh.

Only OFL or otherwise redistributable fonts belong in this directory, because
the repository is public. Trial or commercial fonts stay installed on the local
machine and are named at the front of --font-mono or --font-display in
internal/ui/tailwind/input.css instead.
